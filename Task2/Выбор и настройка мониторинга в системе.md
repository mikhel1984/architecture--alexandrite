## Мотивация

- Существующая система не справляется, часть заказов теряется. Для отладки и оптимизации нужно понимать, какие есть узкие места.
- Мониторинг позволит оперативно реагировать на обнаруженные проблемы.
- Рост числа клиентов приведёт к исчерпанию возможностей существующих мощностей, расширение потребует дополнительных затрат. Прежде всего имеет смысл масштабировать наиболее нагруженные части, для выявления которых нужен мониторинг.

## Выбор подхода к мониторингу

Для MES предлагается использовать USE, так как производительность MES зависит от интенсивности запросов. Для остальных частей можно использовать RED.

## Метрики

- Number of dead-letter-exchange letters in RabbitMQ. Для оценки эффективности обработки сообщений.
- Number of message in flight in RabbitMQ. Для контроля нагрузки и предотвращения перегрузки системы.
- Number of requests (RPS) for internet shop API. Для оценки общей загрузки и её распределения во времени.
- Number of requests (RPS) for MES API. Для оценки общей загрузки и её дальнейшего прогнозирования.
- CPU % for CRM API. Для оценки загрузки CRM и прогнозирования.
- CPU % for MES API. Для определения эффективности работы MES.
- Memory Utilisation for MES API. Для определения эффективности работы MES.
- Memory Utilisation for CRM API. Для определения эффективности работы CRM.
- Number of connections for shop db instance. Оценка необходимости в шадрировании и кэшировании.
- Number of connections for MES db instance. Оценка необходимости в шадрировании и кэшировании.
- Response time (latency) for shop API. Улучшение пользовательского опыта.
- Response time (latency) for CRM API. Улучшение пользовательского опыта.
- Response time (latency) for MES API. Улучшение пользовательского опыта.
- Size of shop db instance. Для избегания переполнения диска и планирования масштабирования.
- Size of MES db instance. Для избегания переполнения диска и планирования масштабирования.
- Number of HTTP 200 for MES API. Эффективность работы MES.
- Number of HTTP 500 for shop API. Детектирование отказов магазина.
- Number of HTTP 500 for CRM API. Детектирование отказов CRM.
- Number of HTTP 500 for MES API. Детектирование отказов MES.
- Number of simultanious sessions for shop API. Оценка загруженности магазина и прогнозирование.
- Number of simultanious sessions for CRM API. Оценка загруженности CRM и прогнозирование.
- Number of simultanious sessions for MES API. Оценка загруженности MES и прогнозирование.

Ярлыки не нужны.
