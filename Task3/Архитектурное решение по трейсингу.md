## Трейсинг

- Internet Shop - Shop API - Shop DB
- CRM - CRM API - Message Queue
- MES - MES API - Message Queue

Для MES помимо времени поступления запроса при трейсинге следует сохранять время обработки, размер свободной памяти, загрузку CPU.

## Мотивация

Трейсинг позволяет отследить слабые места в цепочке вызвово, что даст возможность:

- минимизировать число потерянных заказов
- повысить быстродействие системы
- масштабировать систему для увеличения числа клиентов

## Предлагаемое решение

Трассировка с помощью OpenTelemetry, визуализация в Jaeger. [Схема](./jewerly_c4_model.drawio).

## Компромиссы

- Невозможно или дорого добавить трассировку в стороннее ПО
- Повышение детализации цепочки вызовов приведет к увеличению объема доработки компонентов

## Безопасность

- Аутентификация пользователей, входящих в систему
- Использование токенов вместо персональных данных
