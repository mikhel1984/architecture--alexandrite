## Существующие проблемы

- задержка в обновлении данных MES
- низкое быстродействие при расчете стоимости в MES
- потеря данных при приеме заказов

## Потенциальные проблемы

- снижение быстродействия, увеличение числа отказов с ростом нагрузки на систему

## Устранение нежелательных ситуаций

- Внедрение логирования, мониторинга, трейсинга для выявления узких мест и ситуаций, приводящих к потерям заказов
- Кэширование для уменьшения нагрузки на базу данных и повышения быстродействия при просмотре списка заказов
- Масштабирование нагруженных частей системы для повышения надежности и быстродействия

## Приоритеты

- Логирование - чтобы отловить потери заказов
- Мониторинг, трейсинг - чтобы оптимизировать систему
- Кэширование - чтобы повысить быстродействие при отображении данных
- Масштабирование - чтобы повысить надежность при работе под нагрузкой

Целевая архитектура через полгода: MES развернут в нескольких экземплярах, к базам данных применили шадрирование, добавили кэширование.
